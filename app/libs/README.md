# Библиотеки

Здесь собраны примеры работы с внешними библиотеками, которые используются в проекте. Все библиотеки настроены как внешние зависимости (external), что означает, что они не включаются в основной бандл и должны быть установлены отдельно.

## Зачем это нужно?

Когда библиотека помечена как external, она не попадает в финальный бандл приложения. Это дает несколько преимуществ:

- **Быстрая первая установка** - проект собирается быстрее, так как не нужно бандлить большие библиотеки
- **Кеширование** - браузер может кешировать библиотеки отдельно от вашего кода
- **Обновления** - можно обновлять библиотеки без пересборки всего проекта

## Установка библиотек

Перед использованием любой библиотеки из этой папки, её нужно установить через npm:

```bash
npm install @vueuse/core
npm install vee-validate yup
```

Для TypeScript проектов также могут понадобиться типы:

```bash
npm install @types/yup --save-dev
```

## VueUse

Коллекция полезных композаблов для Vue 3. Огромное количество готовых решений для типичных задач.

**Что умеет:**
- Работа с DOM (размеры окна, скролл, позиция мыши)
- Утилиты для работы с данными (debounce, throttle, toggle)
- Интеграции (clipboard, localStorage, media queries)
- И еще куча всего полезного

**Примеры:** Смотри в папке `vueuse/`

**Документация:** https://vueuse.org/

## VeeValidate

Мощная библиотека для валидации форм. Работает отлично с Yup для создания схем валидации.

**Что умеет:**
- Валидация полей формы
- Асинхронная валидация (проверка на сервере)
- Условная валидация
- Кастомные правила
- Интеграция с Yup схемами

**Примеры:** Смотри в папке `vee-validate/`

**Документация:** https://vee-validate.logaretm.com/

## Как добавить новую библиотеку?

1. Добавь библиотеку в `external` в `project-config/vite.ts`
2. Создай папку с примерами в `app/libs/`
3. Добавь информацию о библиотеке в этот README
4. Не забудь указать команду установки!
